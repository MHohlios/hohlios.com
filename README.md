# hohlios.com

Personal site for Michael Hohlios. Static HTML/CSS/JS — no build step.

- `index.html` — the page
- `styles.css` — layout + Celadon theme tokens (`celadon` dark, `sky` light)
- `site.js` — theme toggle (persisted in `localStorage`) and click-to-copy email
- `assets/` — portrait and work images

Preview locally: `python3 -m http.server 8000` then open http://localhost:8000.
